Run these with curl (bash/WSL) or Invoke-WebRequest (PowerShell).

 1. NOAA SPACE WEATHER PREDICTION CENTER (SWPC)
    Used by: SOLARIS agent
    Base URL: https://services.swpc.noaa.gov
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## Real-Time Solar Wind (DSCOVR / SOLAR-1 instrument)
curl "https://services.swpc.noaa.gov/json/rtsw/rtsw_wind_1m.json" -o solar_wind_realtime.json
# Returns: 1-minute cadence solar wind speed, density, temperature (last ~7 days)
# Fields: time_tag, speed, density, temperature, status

## GOES Proton Flux (Solar Particle Events — SEP/SPE detection)
curl "https://services.swpc.noaa.gov/json/goes/primary/integral-protons-7-day.json" -o goes_protons.json
# Returns: 5-minute proton flux at >1, >5, >10, >30, >50, >100 MeV channels
# Use >10 MeV channel threshold of 10 pfu for S1 SPE alert level (NOAA standard)
# Fields: time_tag, flux, energy

## GOES X-Ray Flux (Solar Flare classification)
curl "https://services.swpc.noaa.gov/json/goes/primary/xrays-7-day.json" -o goes_xray.json
# Returns: X-ray flux (0.05–0.4nm and 0.1–0.8nm bands)
# Use for C/M/X solar flare classification
# Fields: time_tag, flux, observed_flux, satellite

## GOES Magnetometer (Geomagnetic disturbance)
curl "https://services.swpc.noaa.gov/json/goes/primary/magnetometers-7-day.json" -o goes_mag.json
# Returns: magnetic field components Hp, He, Hn, total field
# Fields: time_tag, Hp, He, Hn, total, satellite

## Planetary K-Index (Geomagnetic storm level — Kp index)
curl "https://services.swpc.noaa.gov/json/planetary_k_index_1m.json" -o kp_index.json
# Returns: Kp index at 1-minute cadence
# Kp >= 5 = geomagnetic storm; Kp >= 7 = severe; Kp >= 9 = extreme

## Current NOAA Space Weather Scales (R/S/G levels)
curl "https://services.swpc.noaa.gov/products/noaa-scales.json" -o noaa_scales.json
# Returns: Current R (radio), S (solar radiation), G (geomagnetic) storm levels
# R0-R5, S0-S5, G0-G5 — key for crew radiation risk assessment

## 3-Day Space Weather Forecast (human-readable)
curl "https://services.swpc.noaa.gov/text/3-day-forecast.txt" -o 3day_forecast.txt
# Returns: NOAA forecaster narrative for next 72 hours

## 27-Day Outlook (longer range solar activity)
curl "https://services.swpc.noaa.gov/text/27-day-outlook.txt" -o 27day_outlook.txt

## Active Space Weather Alerts & Watches
curl "https://services.swpc.noaa.gov/products/alerts.json" -o active_alerts.json
# Note: endpoint was 404 at time of writing — check swpc.noaa.gov for current path

 2. NASA OPEN SCIENCE DATA REPOSITORY (OSDR)
    Used by: GENE agent (RAG knowledge base + omics data)
    Docs: https://www.nasa.gov/osdr-api/
    Base URL: https://osdr.nasa.gov/osdr/data
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NOTE: OSDR requires a free account for file downloads.
      Register at: https://osdr.nasa.gov
      Metadata queries below are fully public (no auth needed).

## Search all studies (metadata only — no auth required)
curl "https://osdr.nasa.gov/osdr/data/osd/query?term=Inspiration4&from=0&size=20&sort_by=score&sort_order=DESC" -o osdr_i4_search.json
# Returns: Study IDs, titles, descriptions, data types for Inspiration4 studies

## Search for astronaut health / radiation studies
curl "https://osdr.nasa.gov/osdr/data/osd/query?term=spaceflight+radiation+human&from=0&size=20" -o osdr_radiation_studies.json

## Search for immune dysregulation studies
curl "https://osdr.nasa.gov/osdr/data/osd/query?term=spaceflight+immune+astronaut&from=0&size=20" -o osdr_immune_studies.json

## Get metadata for a specific OSD study (example: OSD-665 is an I4 study)
curl "https://osdr.nasa.gov/osdr/data/osd/files/665" -o osdr_study_665_files.json
