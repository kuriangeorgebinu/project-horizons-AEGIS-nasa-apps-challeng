Flow A: Daily Health Check (Passive Monitoring)

USER ACTION: Opens AEGIS dashboard (morning routine)
▼
SYSTEM: Shows Mission Control tab with: • Agent Network (all green = nominal) • Personal vitals summary • Any overnight recommendations (Tier 2 PREVENT) • Radiation forecast for the day
▼
USER ACTION: Reviews recommendations, clicks Accept/Defer USER ACTION: Optionally asks AEGIS via voice: "Any concerns?"
▼
SYSTEM: AEGIS responds with natural language summary "Good morning, Commander. All crew nominal. One recommendation pending: Dr. Okonkwo's sleep schedule adjustment."

Flow B: Recommendation Response (Tier 2 PREVENT)

TRIGGER: PULSE detects cortisol trend (+12% over 3 days) → PULSE notifies AEGIS → AEGIS queries RAG for intervention protocols → AEGIS creates recommendation card
▼
UI UPDATE: New card appears in Recommendations panel • Shows: PULSE → AEGIS attribution • Shows: Detection reasoning • Shows: Recommended intervention • Shows: Evidence source (HRP Protocol X.X.X)
▼
USER ACTION: Clicks one of three buttons [✓ Accept] → Intervention scheduled, crew notified [◷ Defer] → Re-evaluate in 4 hours, stays visible [✕ Dismiss] → Logged for review, removed from active list
▼
SYSTEM: Logs decision, updates crew schedule if accepted SYSTEM: AEGIS confirms via voice panel

Flow C: Emergency Alert Response (Tier 3 PROTECT)

Note: This is a real emergency based on actual sensor data, not a simulation. The What-If Simulator (Flow D) is for planning; this flow is for live response.

TRIGGER: Multi-agent convergence detected (REAL DATA) • SOLARIS: Radiation spike incoming (sensor threshold exceeded) • GENE: Immune markers elevated • PULSE: HR/HRV abnormal • MIRROR: Stress indicators rising
▼
UI UPDATE: Alert panel activates (red border, pulsing icon) AUDIO: Alert tone plays VOICE: AEGIS announces: "Cascade alert detected..."
▼
USER ACTION: Reviews alert, clicks [Confirm Protocol Alpha-3] OR if no response in 30 seconds: SYSTEM: Auto-executes protocol (autonomous mode)
▼
SYSTEM: Opens Spacecraft Simulation View → Triggers via URL: aegis-spacecraft-sim-2d.html?alert=cascade&protocol=alpha-3 SPACECRAFT SIM SHOWS: • Shelter room highlights in green • Astronaut icons animate walking to shelter • Radiation direction indicator (arrow from threat vector) • Real-time crew position tracking • Countdown timer for shelter-in-place duration
▼
SYSTEM: Dashboard shows confirmation • Celebration animation (green pulse, checkmarks) • All agents show synchronized confirmation VOICE: "Protocol Alpha-3 confirmed. Crew moving to shelter." SPACECRAFT SIM UPDATES: • Astronauts arrive at shelter (animated) • Shelter door closes indicator • Status: "All crew secured — 4/4 in shelter"

PROTECT vs What-If: Key Differences

TriggerActual sensor data crosses thresholdsUser clicks What-If button
UrgencyImmediate — auto-executes in 30sNo time pressure
UI StyleRed pulsing alert, audio alarmCalm modal window
Spacecraft SimShows REAL crew positions, live trackingShows PROJECTED movements
OutcomeActual countermeasures activatedEducational — nothing changes

Technical: Dashboard ↔ Spacecraft Sim Communication

Method: URL Parameters + localStorage (no backend required for demo)

Dashboard confirms protocol ↓ window.open('aegis-spacecraft-sim-2d.html?alert=cascade&protocol=alpha-3&severity=critical') ↓ Spacecraft Sim reads URL params on load: const params = new URLSearchParams(window.location.search); if (params.get('alert') === 'cascade') { triggerShelterSequence(params.get('protocol')); } ↓ Sim animates crew to shelter, shows radiation vector

Future (with backend): WebSocket push from server to both dashboard and sim for real-time sync.

Demo Script (5-minute walkthrough)

Minute 0-1: Introduction

"This is AEGIS — our autonomous health monitoring system for deep space missions. Let me show you how it keeps astronauts safe when Earth is 20 minutes away."
  • Show Mission Control tab
  • Point out agent network (all connected to AEGIS)
  • Mention the three tiers: Predict, Prevent, Protect

Minute 1-2: Prevention in Action

"AEGIS doesn't wait for problems — it prevents them. Here, PULSE detected elevated cortisol in Commander Chen, and AEGIS is recommending a sleep adjustment."
  • Scroll to Recommendations panel
  • Click Accept on the cortisol recommendation
  • Show the confirmation animation

Minute 2-3: What-If Planning

"Astronauts can also ask 'what if' questions. Let's simulate a solar particle event."
  • Click What-If button
  • Select SPE scenario
  • Run simulation
  • Show agent cascade and recommendation

Minute 3-4: Emergency Response

"When prevention isn't enough, AEGIS protects. Watch what happens in a cascade alert."
  • Trigger the cascade alert
  • Click Confirm Protocol
  • Show celebration animation

Minute 4-5: Voice Interaction

"And astronauts can just ask AEGIS directly."
  • Click microphone
  • Ask "What's the crew status?"
  • Show typewriter response

Closing

"AEGIS: Predict problems days early. Prevent them with intervention. Protect the crew when all else fails. Zero Earth dependence."
