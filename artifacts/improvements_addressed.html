Status note (October 2026). This is a historical change log (HRV was later removed). Some parts describe the original concept, not the software as built. Where they differ, this box is correct:
  • Built and running: AEGIS coordinator + 4 specialist agents (PULSE heart rate/SpO₂, GENE IL-6, MIRROR sleep, SOLARIS radiation), rule-based detection, trend forecasts, cascade detection, PREVENT/PROTECT protocols, DeepSeek explanations with an automatic fact check, phone alert to the on-call flight surgeon.
  • Data: vitals are simulated (no wearable hardware). IL-6 is modelled from stress and radiation, not measured. Radiation is judged against the Mars-transit background measured by Curiosity RAD (1.84 mSv/day). Real NASA data (Inspiration4 / OSDR OSD-575, NTRS abstracts) is used to check the rules and as the RAG knowledge base; nothing is “trained” on it.
  • Prediction scope: in the demo AEGIS forecasts a cascade about 2–3 minutes before the third domain crosses its limit (the demo runs a compressed 6-minute build-up). On a mission the same trend method would work on hours-to-days data; that has not been validated.
  • Not built (concept only): HRV, CRP, cognitive tests (PVT/n-back), live DSCOVR/GOES feeds, RadLab dose model, z-score/EWMA baselines, genomic (TP53) analysis, a 30-second auto-execute override. PROTECT protocols are raised for a human to confirm.
  • Category strategy now: Best Mission Concept (primary), Best Use of Technology (secondary).
Current numbers and test results: README.md and AEGIS-Accuracy-Report.html.
