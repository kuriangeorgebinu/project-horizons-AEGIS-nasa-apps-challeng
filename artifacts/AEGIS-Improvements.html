⚙️ Running the backend

Auto-reload hangs on Windows (M1 below), so restart the backend after Python changes. Startup takes ~40 s:

Get-NetTCPConnection -LocalPort 8000 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }
$env:PYTHONUTF8='1'
Start-Process -WindowStyle Hidden uv -ArgumentList "run uvicorn main:app --host 127.0.0.1 --port 8000" `
  -RedirectStandardOutput server.log -RedirectStandardError server.err.log
